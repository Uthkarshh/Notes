# Core screen tour

Captured from the API 34 Android emulator with synthetic test data. The tour changes to dark mode for the final three captures.

The [Phase 2 tour](phase2/README.md) adds reminders, reflections, notifications, data transfer, history, and share capture.
The [Phases 3/4 tour](phase34/README.md) adds metadata, local images, launcher tools, security/backup controls, insights, and real widget views.

The [UI/UX redesign proposal](../design/README.md) reviews these captures alongside the current Compose code and specifies the proposed layouts, interactions, design tokens, and implementation milestones.

The [redesign milestone 1 tour](redesign-m1/README.md) shows the implemented autosave, Today, contextual-consent, and AMOLED changes.
The [redesign milestone 2 tour](redesign-m2/README.md) shows live capture previews, priority controls, filing suggestions, batch selection and deletion Undo.
The [redesign milestone 3 tour](redesign-m3/README.md) covers collection views, compact detail, Discover, field review, Vault and large text.
The [milestone 4 adaptive tour](redesign-m4/README.md) shows collection, Vault, Search and Settings panes in a resized window.
The [milestone 4 quality tour](redesign-m4-polish/README.md) adds four appearance modes, Board movement and 200% text in RTL panes/settings.
